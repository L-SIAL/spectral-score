# LH Spectral Palette

The installable iPad app: https://l-sial.github.io/spectral-score/

Second app, **LH Audio Editor** (for lesson recordings): https://l-sial.github.io/spectral-score/editor/
— open it in Safari › Share › Add to Home Screen.

## Changing the app from the iPad
1. Claude app › menu (☰) › **Code** (or claude.ai/code in Safari).
2. Tap the GitHub button by the message box › **Change repository** › **L-SIAL/spectral-score**.
3. **Change branch** › **main**.
4. Type the change you want and send it. Claude makes the next version.
5. Tap **Create PR** (or the pull request link).
6. On GitHub: **Merge pull request** › **Confirm merge**.
7. Wait about 2 minutes while GitHub rebuilds the app.
8. Close the app fully (swipe it away) and open it again while online.
9. The version bottom left has gone up by one.

If the repository is missing in step 2: Safari › github.com/settings/installations › Claude › Configure ›
Repository access › spectral-score › Save.

Back on the Mac: tell Claude there "the iPad made vNN" before changing anything.
(For Claude: see CLAUDE.md.)
